# MHW Client Portal User SOP

## Purpose

Use this guide to help hotel clients sign in and review their entertainment schedule.

## Sign In

1. Go to the MHW Client Portal sign-in page.
2. Enter the email address MHW has on file.
3. Click `Send sign-in link`.
4. Open the email from MHW.
5. Click the secure sign-in link.
6. Click `Continue to portal`.

If the email does not arrive, check spam/junk first, then contact MHW.

## Magic Link Timing

- Sign-in links expire after 30 minutes.
- Each sign-in link can only be completed once.
- After signing in, the portal session stays active for 12 hours.
- If the browser is closed but the 12-hour session is still active, return to the portal URL directly.
- If the user logs out or the 12-hour session expires, request a new sign-in link.

## Home Page

The Home page gives a quick view of the property's entertainment status.

Clients can review:

- This week's entertainment
- This month and next month's entertainment
- Schedule progress
- Holiday coverage
- Upcoming booking highlights

## This Week's Entertainment

1. The current day opens by default.
2. Click any day to expand or collapse it.
3. Click `View details` on a booking to see more information.

## Calendar Page

The Calendar page shows the full entertainment schedule.

Available range options:

- Month
- Week

Available format options:

- Calendar
- List

Clients can:

- Move between months/weeks.
- Review bookings added since Sunday.
- Open booking details.
- Submit performer feedback from a booking detail page.
- Download calendar events.
- Review times in the property's timezone.

Click `Added this week` to see the bookings that were newly added during the current week.

## Booking Details

Booking details may include:

- Date
- Time
- Venue
- Performer
- Performer bio
- Performer headshot
- Social media link, when available
- Website link, when available
- Promo video, when available
- MHW contact information

Clients can click `Submit feedback` from a booking detail page to share a performer rating and hotel feedback notes for that specific booking. The portal connects the feedback to the signed-in client contact automatically.

## Profile Page

The Profile page shows the client's portal contact information:

- Contact name
- Email address
- Property
- MHW account manager
- Account manager contact information, when available

## Need Help

If information looks incorrect or needs to be updated, contact MHW.
